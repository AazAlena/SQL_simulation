# Генератор отчётов на основе SQL-подобного языка (sqlsim)

Консольная утилита, которая принимает SQL-подобный запрос (например,
`SELECT name, avg(grade) FROM students.csv GROUP BY name`), читает данные из
CSV-файлов и выводит результирующую таблицу-отчёт.

> Текущая версия — каркас проекта: окружение сборки настроено, программа
> выводит `Hello, World!`. Реализация парсера, исполнителя и форматтера будет
> добавлена в последующих итерациях.

## Структура проекта

```
SQL_simulation/
├── CMakeLists.txt          # настройка сборки (CMake >= 3.10, C++17)
├── include/
│   └── sqlsim/             # публичные заголовки
│       └── hello.h
├── src/                    # исходный код (пары .cpp/.h)
│   ├── main.cpp
│   └── hello.cpp
└── tests/
    └── data/
        └── students.csv    # тестовые данные
```

## Сборка (out-of-source)

```bash
cmake -S . -B build      # конфигурация (создаёт каталог build/)
cmake --build build      # компиляция
```

## Запуск

```bash
./build/sqlsim           # либо: cd build && ./sqlsim
```

Ожидаемый вывод:

```
Hello, World!
```

## Сторонние библиотеки

Не используются — проект собирается только стандартной библиотекой C++17.
